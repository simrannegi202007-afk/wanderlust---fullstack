# Wanderlust

A travel accommodation listing platform for discovering places to stay.

**Project Status:** In Development · Phase 1 of 3 completed

## Overview

Wanderlust is a web application focused on travel accommodation listings. The project aims to provide a platform where users can explore places to stay through a structured and user-friendly interface.

The application is being developed incrementally, with its architecture and functionality evolving across multiple development phases.

## Tech Stack

The project currently uses the following technologies:

- **Runtime:** Node.js
- **Backend:** Express.js
- **Database:** MongoDB
- **ODM:** Mongoose
- **Templating Engine:** EJS
- **View Layouts:** ejs-mate
- **Version Control:** Git and GitHub

## Project Structure

## Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

Ensure the following are installed:

- [Node.js](https://nodejs.org/)
- [MongoDB Community Server](https://www.mongodb.com/try/download/community)
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/simrannegi202007-afk/wanderlust---fullstack
```

**2. Navigate to the project directory**

```bash
cd "MAJOR PROJECT"
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure the database**

Ensure MongoDB is running and configure the database connection according to the project's settings.

**5. Start the application**

```bash
node app.js
```

**6. Open the application**

Navigate to the local URL and port configured in `app.js` in your browser.
